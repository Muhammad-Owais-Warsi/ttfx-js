Names, untangled

Two packages, three commands. Install names and run names differ on purpose:

You typeWhat it is
npm i ttfx-jsInstalls the CLI package
ttfx / ttfx-jsRuns it — both commands, same binary (ttfx matches upstream docs)
npm i ttfx-nodeInstalls the API package (no command — import it)
ttfx-cliDead name from release day — deprecated, ignore it

CLI docs

npm i -g ttfx-js
echo "hello" | ttfx beams
git log --oneline -10 | ttfx matrix
npx ttfx-js decrypt --help    # options for one effect
InputHow
Pipeecho "hi" | ttfx decrypt (PowerShell, cmd, bash)
Filettfx --input-file banner.txt beams
Pick one of 37ttfx <effect> --help lists each effect's flags
Surprise mettfx --random-effect (+ --include-effects / --exclude-effects)
Deterministicttfx --seed 1 decrypt — same seed, same frames
Canvas--frame-rate 60 --canvas-width 40 --canvas-height 10 --wrap-text
Exit codes0 played · 1 empty input / error / Ctrl-C

Binaries (~2 MB) arrive as platform packages npm picks automatically. Same speed and rendering as the native Rust build.

API docs

npm i ttfx-node
import { play, getFrames, listEffects } from 'ttfx-node';

await play('Deploy complete', 'decrypt');              // animates, cleans up
const frames = getFrames('hi', 'beams', { seed: 1 }); // pure ANSI strings
FunctionDoes
play(input, effect, opts?)Animates in your terminal. Fresh line in, cursor restored out. Rejects INTERRUPTED on Ctrl-C. Plain final text under NO_COLOR/pipes.
getFrames(input, effect, opts?)Sync string[], deterministic per seed. Machine-independent (terminal size never read).
listEffects()All 37 names.
stripAnsi(s)Plain text from a frame.
OptionDefaultNotes
seedOS entropySet it in tests; snapshots never flake
frameRate60Pacing hint for players (0 = unpaced)
canvasWidth / canvasHeighthugs inputFix both to align multi-play layouts (max 1000×500)
effectArgseffect defaultsAny flag, CLI-validated: ['--typing-speed', '5']. Discover via npx ttfx-js <effect> --help
maxFrames10000Hard cap 100000 — also your memory guard
randomEffectfalseSeeded pick; filter with include/excludeEffects
noColor / xtermColorsfalsePlain layout / 8-bit palette for limited terminals
reuseCanvas (play only)falseReplay in the previous run's rows (same text): omit first call, set after

Errors are descriptive Errors: NO INPUT. for blank text, CLI text for bad effects/flags, pre-engine errors for oversized input. Baked from the same engine tag as the CLI — CI fails the release if they ever render differently.

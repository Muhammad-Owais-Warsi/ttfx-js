Terminal text effects, everywhere.

One fast engine with 37 effects — shipped as a static binary, a Node API, and WebAssembly that paints straight to canvas. What you see below is the engine itself, looping every effect live.

⌁ CLI Pipe text in, pick an effect. One static binary, no runtime. npx ttfx-js decrypt ⬢ Node API play() for terminals, getFrames() for headless rendering. Deterministic per seed. ◈ Web Same engine as WebAssembly. Packed cells straight to <canvas> — no emulator.

Install

CLI — no install at all

npx ttfx-js decrypt            # runs once, pipe text in
echo "hello" | npx ttfx-js beams

CLI — global

npm i -g ttfx-js
echo "hello" | ttfx beams        # ttfx and ttfx-js both work

Library (Node + browser)

npm i ttfx-node

Effects, engine and CLI design by TerminalTextEffects, via the ttfx Rust port (Windows support from this fork). MIT.

CLI reference

One static binary. Pipe text in, pick an effect.

<producer> | ttfx [terminal options] <effect> [effect options]

ttfx --help                 # all 37 effects and the terminal options
ttfx <effect> --help        # options for one effect
ttfx --random-effect        # surprise me (--include-effects / --exclude-effects)

Terminal options go before the effect name (canvas size, colors, frame rate, wrapping); effect options go after it. Also useful: --seed (deterministic runs), --palette HEX,.. + --bands (theme the word in field stripes), --print-completion bash|zsh.
